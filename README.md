# 🇰🇬 TiliTili Flashcards
> Веб-приложение для изучения кыргызского и русского языков через интерактивные карточки с геймификацией.
---
## 📖 О проекте
**TiliTili Flashcards** — публичное мобильное веб-приложение для тренировки словарного запаса кыргызского и русского языков. Пользователи проходят тематические уровни, зарабатывают опыт и растут от «Новичка» до «Мастера».
**Языковая пара:** Кыргызский ↔ Русский  
**Приоритетная платформа:** Смартфон (PWA), с поддержкой десктопного браузера
---
## ✨ Ключевые возможности
- 🎴 **Два режима обучения** — Быстрая сессия и Уровни по топикам
- 🧠 **Умный повтор** — слова, в которых вы ошибаетесь, появляются чаще
- 🏆 **Система XP и уровней** — 10 уровней от Новичка до Мастера
- 📚 **Тематические уровни** — слова сгруппированы по темам (Еда, Природа, Животные и др.)
- ➕ **Управление словарём** — добавление слов вручную или импорт через Excel
- 👤 **Простая регистрация** — только username и пароль, без email
---
## 🎮 Игровые режимы
### Быстрая сессия
Подборка из 10–20 слов по одному из сценариев:
- 🎲 **Случайные слова** — рандомная подборка из всего словаря
- 🔁 **Повторение** — слова, которые пользователь уже видел
- ⚠️ **Слабые места** — слова с процентом ошибок > 40%
### Уровни по топикам
- Каждый топик = отдельный уровень
- Уровни открываются последовательно
- Прохождение уровня разблокирует следующий
### Типы вопросов
- **Тип А:** Выбор правильного перевода из 4 вариантов
- **Тип Б:** Выбор из 2 похожих слов (для закрепления)

## 🏅 Система прогресса
| Уровень | Звание | Нужно XP |
|---------|--------|----------|
| 1 | Новичок | 0 |
| 2 | Ученик | 100 |
| 3 | Знакомый | 250 |
| 4 | Понимающий | 450 |
| 5 | Говорящий | 700 |
| 6 | Уверенный | 1 050 |
| 7 | Опытный | 1 500 |
| 8 | Продвинутый | 2 100 |
| 9 | Знаток | 2 900 |
| 10 | Мастер | 4 000 |
**Начисление XP:**
- Завершить быструю сессию → +10 XP
- Сессия с результатом ≥ 80% → +25 XP
- Пройти уровень топика впервые → +50 XP
- Перепройти топик с результатом ≥ 90% → +15 XP

## 🗂 Структура словаря
Каждая единица словаря содержит:
- Слово/фраза на кыргызском и русском
- Тип: `word` / `phrase` / `idiom`
- Топик (тема)
- Часть речи (опционально)
- Сложность: 1–3

## 🚀 Быстрый старт
```bash
# Клонировать репозиторий
git clone https://github.com/your-username/tilitili-flashcards.git
cd tilitili-flashcards
# Установить зависимости
npm install
# Настроить переменные окружения
cp .env.example .env
# Заполнить DATABASE_URL, JWT_SECRET в .env
# Применить миграции базы данных
npx prisma migrate dev
# Запустить в режиме разработки
npm run dev
```
Открыть [http://localhost:3000](http://localhost:3000)
